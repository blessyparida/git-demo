# Git & GitHub Demo

Welcome to my Git and GitHub demonstration repository!

This repository is created to understand and practise the fundamentals of Git and GitHub, including version control, branching, merging, and collaboration.

## About This Repository

The purpose of this project is to explore how developers manage code changes and collaborate using Git and GitHub.

## Topics Covered

- Git Installation and Configuration
- Initializing a Repository (`git init`)
- Staging Changes (`git add`)
- Committing Changes (`git commit`)
- Checking Repository Status (`git status`)
- Creating Branches (`git branch`)
- Switching Branches (`git switch`)
- Merging Branches (`git merge`)
- Handling Merge Conflicts
- Pushing Code to GitHub (`git push`)
- Pulling Changes (`git pull`)

## Common Git Commands

| Command | Description |
|---|---|
| `git init` | Initialize a repository |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Commit changes |
| `git status` | Check repository status |
| `git branch` | List branches |
| `git switch -c feature` | Create and switch to a branch |
| `git merge feature` | Merge a branch |
| `git push` | Push changes to remote |
| `git pull` | Fetch and integrate changes |

## Learning Goals

1. Understand version control.
2. Learn how Git tracks changes.
3. Practise working with multiple branches.
4. Understand merge conflicts and their resolution.
5. Learn how developers collaborate through GitHub.
